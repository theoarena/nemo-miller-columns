## [1.0.0] - 2026-11-06
### Added
- The focused column filters as you type. The match is a case-insensitive prefix over files and folders in that folder only. A chip under the header shows the query in the column color, and the list adds top padding while the chip is visible so the first row stays clear. Escape clears the query, Backspace edits it, and shortcuts, rename, and new folder do not start a search. Each column keeps its own query; a new column starts empty (`83d67310d7fc6beabbf2732326d4348b6591da09`).
- Visible copy follows the system locale through stdlib gettext. English strings stay in the sources and in menu dispatch; `translations/pt` supplies the current Portuguese UI, and a missing catalog leaves the English msgid (`9abc24a646c7378820f74dab4f146373c04f6f6a`).
- The Nemo toolbar gains a Miller Columns button beside icon, list, and compact view. Ctrl+4 still toggles the same view. While Miller is on, the previous view icon is released without switching Nemo's radio action; leaving Miller reattaches that action and keeps the buttons icon-only (`17af74c14ea564d20a0e0aa5dd4d3bd83c206142`).
- The column context menu keeps Abrir / clipboard / rename / trash / Propriedades and adds Nemo actions, the Scripts submenu, and `Nemo.MenuProvider` items at popup time. A blank-area click clears the selection, prunes columns to the right, and shows Nova Pasta, Colar, folder Propriedades, plus `Selection=none` actions. Launch stays in `miller.nemo_actions` / `miller.nemo_extensions` via `GLib.spawn_*` and `Gio.AppInfo`, not in `miller/ui` (`f308a21e3dbee96ddbcee0a120b458d57f46d934`).
- Miller Columns Nemo extension: in-process GTK3 column view with per-folder preference, keyboard navigation, Finder-style preview, toolbar toggle (`Ctrl+4`), and leaves a reserved location alone (`6d51b46e4488deca3e69c522121064037aaa1630`)
- A column selects several rows. Ctrl+click toggles a row. Shift+click and Shift+arrows extend from the anchor. Ctrl+A selects every real row and leaves the empty-folder placeholder alone. Copy, cut, and trash act on that selection. Enter and Abrir open every selected file and skip folders; a single selected folder still opens in the next column (`a52fc2a711c06de7d60d81b7891ac2a617c6085e`)
- Drag publishes `text/uri-list`. A drop copies or moves through `org.Nemo.FileOperations` `CopyURIs` / `MoveURIs`, queued asynchronously because a synchronous call on Nemo's bus deadlocks. Same filesystem moves, a different filesystem copies; Ctrl copies, Shift moves, Ctrl+Shift links. A link is a unique local symlink (`name`, then `name 2`) and is removed if a later link in the same drop fails. Alt shows Mover aqui, Copiar aqui, Criar link aqui, and Cancelar; dismissing the menu finishes the drag (`a52fc2a711c06de7d60d81b7891ac2a617c6085e`)
- Each column watches its directory with `Gio.FileMonitor` (`WATCH_MOVES`). Changes debounce about 200 ms into a reload that keeps the selected names and does not notify the board when that set is unchanged. The reload waits while an inline rename entry is open (`a52fc2a711c06de7d60d81b7891ac2a617c6085e`)
- The context menu Abrir com lists recommended applications for the selected files, then Outro aplicativo…. The item stays disabled when nothing is selected or any selected row is a folder. A mixed selection only lists apps that can open every selected type (`a52fc2a711c06de7d60d81b7891ac2a617c6085e`)

### Changed
- Opening a column lists the folder off the GTK thread via `list_directory_async`. Destroying the column (another click, Up/Down onto a different folder, or Left that prunes it) cancels that listing. Delete, paste, rename, the hidden-file toggle, and the directory monitor still reload on the GTK thread because those callers need the new rows before they return. Up/Down opens the next column on the following main-loop turn. The Loading… row is inserted but still never visible in Nemo; a large folder such as `/bin` still appears all at once. That remains open (`8708975ac3cb208828ab5e722dba27f6dfb9f42d`).
- Up/Down onto a folder waits 180 ms before the next column is listed. The highlight moves at once. A click, a file row, Right, and Enter still open immediately, and any of those cancel a folder the keys had not settled on (`55f6991e9c269d761c54d25753f7b4ceac8b3b09`).
- A reserved location is any directory whose `metadata::nemo-reserved-view` attribute is the string `true`. Miller reads that attribute and does not pack columns or store a view preference there. A child directory without the attribute can still host columns.
- `miller.data` is a facade. Listing, view preference, clipboard, file transfer, and in-window navigation live in `miller.listing`, `miller.preference`, `miller.clipboard`, `miller.transfer`, and `miller.session`. `MillerColumn` keeps init and file actions; rows, keyboard, and the context menu are mixins. Public imports stay on `miller.data` and `miller.ui.column`, including the names tests rebind (`4b00384944fa507d1963d3ad012b08527fb29504`)
- Propriedades opens Nemo's stock properties window through an async `org.freedesktop.FileManager1.ShowItemProperties` call (`show_item_properties`). One or many selected files and folders are passed in list order. The custom `Gtk.Dialog` is gone (`ce442cdef4a28fb9b3f0fc916f7a6584c56045b5`)
- Column strip stays scrolled to the right edge, including on resize, so the last column or the preview stays fully visible (`258f0c7c664266b10b27bfd4e13b6b791f9d7ad5`)
- Only the current column uses the theme accent; the breadcrumb selection is neutral (`258f0c7c664266b10b27bfd4e13b6b791f9d7ad5`)
- Preview fills the remaining width, content is a fixed 360px block aligned to the start, no open button. Icon tiles use the icon's dominant color, or the theme accent for symbolic/near-grey icons (`258f0c7c664266b10b27bfd4e13b6b791f9d7ad5`)
- Preview metadata rows drop Tipo (`mime_description`) and Caminho (`path`): `PreviewPane.update_file` packs `_PREVIEW_METADATA_FIELDS` (Tamanho, Criado, Modificado, Último acesso, Permissões). The properties dialog still packs the full `_METADATA_FIELDS` via `pack_metadata_rows` default. Heading already shows the type; path remains elsewhere (`e138dd7c1cc76b798accfc91f73635fca624208d`)
- One click opens a folder. Files follow Nemo `click-policy` (`single` opens on first click; `double` or unset keeps select + double-click open) (`258f0c7c664266b10b27bfd4e13b6b791f9d7ad5`)
- List selection is `Gtk.SelectionMode.MULTIPLE`. The notify path is `selected-rows-changed`. `get_selected()` is the entry only when exactly one real row is selected. More than one row emits `on_select(column, None)`; the board prunes the columns to the right and does not open a folder (`a52fc2a711c06de7d60d81b7891ac2a617c6085e`)
- `PreviewPane.update_selection` shows "N itens selecionados", a subtitle that counts folders and files (a count of zero is omitted), and the sum of the file sizes. Folders are not walked (`a52fc2a711c06de7d60d81b7891ac2a617c6085e`)

### Fixed
- Opening Miller no longer forces a synchronous column reload: `set_show_hidden` skips `refresh` when the value is unchanged, and the board is created with Nemo's show-hidden preference so `_attach_hidden_sync` stays a no-op. That keeps `_load_async` alive long enough for the Loading… row to paint. Folder-view JSON and `org.nemo.preferences` Settings are reused across resolves instead of reopening on every navigation (`0877bb613ad929339788fe8ec4f6272c6b382589`).

- Copy, cut, and paste follow the files selected in the focused Miller column. Plain Ctrl+C/X/V is consumed while that column has focus, so Nemo's Edit accelerators do not publish the hidden view's selection. A second copy replaces the first after the main loop turns, including names with spaces and accents. Paste is `CopyURIs` / `MoveURIs` on `org.Nemo.FileOperations`; a bad URI, a missing source, or a read-only folder is logged with `[miller]` and does not raise. A single selected folder receives the paste. The column reloads and selects `name (copy).ext` (`7c4a6698d2667767d579263b9751a439d1443e7d`).
- A leading Space in a column no longer opens the file or starts a search. The key is left for other Nemo handlers; if nobody consumes it, `org.nemo.Preview.ShowFile` previews the first selected entry (`addb65a57e33f81dc6cf19f1d86409160dedaf86`).
- A folder click moves the path bar to the opened directory. The accent and keyboard focus stay on the clicked column. A file click returns the bar to that file's folder. Choosing the folder that is already open does not ask Nemo again, and a click back to a file in the folder Nemo already shows, before the flush, does not navigate (`c6abde9b6a04cadcb231ac3c0d0435ac7af268ff`).
- Entering a folder with Right or Enter shows the preview when the first selected row is a file. A folder row stays highlighted without opening a child column (`1953358b28c8386853a48660d18d2e7fcd2abd78`)
- Equilux hover returns on Miller rows: keep `outline-width: 0` to hide the inset focus ring, but do not clear `box-shadow` — hover is `row.activatable:hover` inset fill (`e9d637c5b99f826b200cbc1c542d2e3abdf517c6`)
- Selected rows no longer show the GTK inset focus ring as an internal light border: `.mc-row` sets `outline-width: 0` (and `border-width: 0`), leaving background-only selection (`9c1365ef5d6167f335ac9a90a21b58f29bc8ac5f`)
- Abrir com menu icons are forced to 16px via `image.set_pixel_size(_MENU_ICON_SIZE)` in `_app_item`, so apps with large FileIcon entries match the others (`e138dd7c1cc76b798accfc91f73635fca624208d`)
- Keyboard focus follows the active Miller column via `ListBoxRow` (not `ListBox`): Right enters child rows, Left returns to the parent, empty folders stay put, and refresh/rename keep arrows inside the column (`68aa2391d21492c9ec850c6f0680be1290db54c0`)
- The native folder view no longer flashes for one frame under the columns: while Miller is active, an overlay `show` schedules `hide()` at `GLib.PRIORITY_HIGH_IDLE`, before GDK redraw (`ae4cbd5cc7321f3954641fd4474d42f7bc7d1d75`)
- Arrow keys no longer ask Nemo to open every folder they pass through, and a late echo of that request no longer pulls the board backward: the board moves on the key, Nemo is asked once 150 ms after the last arrow (`_schedule_navigation` / `flush_navigation`), a path still in `_miller_nav_inflight` is ignored by `get_widget` (no `set_root_path`, `_miller_uri` kept, `show_all` only when the board is created), any other location calls `_reset_navigation`, deactivate flushes a pending target before the board is destroyed, and window destroy (`_bind_window`) clears the timer (`ae4cbd5cc7321f3954641fd4474d42f7bc7d1d75`)
- Miller state lives on each `NemoWindowSlot`, not the window. Switching tabs no longer destroys the other tab's board or writes the folder view preference. `location-changed` identifies the slot before `get_widget`. `active` sets a view-sync guard so Nemo's native radio sync is ignored. Pending navigation waits until that tab is active again. Reserved-location and non-directory leaves deactivate only the resolved slot (`258f0c7c664266b10b27bfd4e13b6b791f9d7ad5`)
- Returning to a Miller tab puts keyboard focus back on the last selected folder or file: the board focuses the accent column instead of `focused_index`, and the grab runs on an idle after the tab switch so the hidden native view and `GtkNotebook` cannot take it back (`258f0c7c664266b10b27bfd4e13b6b791f9d7ad5`)
